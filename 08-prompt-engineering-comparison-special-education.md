# Prompt Engineering for Special Education: A Controlled Comparison

**Role:** Designer and evaluator
**Program:** Inteligencia Artificial Generativa — Universidad Politécnica Salesiana del Ecuador
**Focus:** Multiple disabilities · Universal Design for Learning

---

## The challenge

"Use AI to help you plan" is advice that sounds complete and isn't. The same tool, asked the same
question in two different ways, returns work of very different quality — and a teacher under time
pressure has no way to tell which version they are getting.

That gap matters more in special education than almost anywhere else. A generic activity handed to a
student with multiple disabilities is not merely unhelpful; it is a lesson the student cannot enter.

## The approach

Rather than argue the point, I ran it. I wrote two prompts for the same instructional task — an activity
for a seven-year-old with multiple disabilities, emerging communication, and sensory sensitivities — and
executed both.

Version 1 is the prompt a busy teacher actually writes: role, short context, one-line task. Version 2
specifies the expert frame (special education, multiple disabilities, UDL-based instructional design),
the environment, the learner profile, the required components, and the ethical constraints on the output.

Both outputs appear in the document side by side, unedited, so the difference is visible rather than
asserted.

## What I delivered

- Two controlled prompt versions for an identical instructional task
- Both AI outputs reproduced verbatim for direct comparison
- Analysis of what the expert prompt adds: learning objective, reasonable adjustments, formative
  assessment strategy, and rights-based framing
- Conclusion positioning advanced prompt design as a professional competency for special educators

## What this demonstrates

Prompt engineering treated as an evaluable design discipline rather than a knack. The basic version
returns "the student observes and touches colored objects" and calls the assessment "observe whether the
student participates." The expert version returns a named learning objective, pictogram-based
anticipation, environmental stimulus reduction, extended response time, partial physical support that
preserves autonomy, and an observation protocol with defined indicators.

Same model. Same task. The difference is the design of the request.

The activity produced by the expert prompt is the one built out in project 09.
